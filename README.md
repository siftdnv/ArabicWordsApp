## Описание
Приложение для изучения арабских слов. Позволяет добавлять, просматривать, редактировать и удалять слова с переводом, транскрипцией и грамматической информацией.

## Выбранная тема
Изучение иностранных слов (арабский язык) - вариант 9 из списка

## Основные функции
- Добавление новых слов (арабское слово, перевод, транскрипция, грамматика)
- Просмотр списка всех слов
- Просмотр подробной информации о слове
- Редактирование слова
- Удаление слова
- Проверка ввода (поля не могут быть пустыми)
- Сохранение данных после перезапуска

## Технологии
- **Язык:** Java
- **Хранение данных:** SQLite
- **Интерфейс:** XML, RecyclerView
- **Минимальная версия Android:** API 24 (Android 7.0)

## Инструкция по запуску
1. Клонировать репозиторий: `git clone https://github.com/siftdnv/ArabicWordsApp.git`
2. Открыть проект в Android Studio
3. Подключить Android-устройство или запустить эмулятор
4. Нажать Run (зелёный треугольник)

## Что реализовано
- [x] 3 экрана (список, добавление, детали)
